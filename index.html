macOS 版 · Apple Silicon / macOS 11+

目前是内测：没有签名和公证，用一条命令在本机构建并安装（3–8 分钟，会装 uv、独立 Python 3.12 和依赖），产物直接进「应用程序」。

curl -fL --max-time 30 --retry 2 -o ~/sen-install.command https://178497.github.io/sen/one-click-mac.command chmod +x ~/sen-install.command && ~/sen-install.command

首次打开被系统拦下时：macOS 14 及更早可以右键 Sen.app → 打开；macOS 15 起右键不再有效，去「系统设置 → 隐私与安全性 → 仍要打开」。

训练走 fp16 LoRA（不用 4-bit 量化），比 NVIDIA 显卡慢，但功能一致。数据在 ~/Library/Application Support/Sen。

01 · 前置条件

需要先安装 Ollama（本地推理引擎，Windows 与 macOS 相同）。首次启动会引导你下载对话模型，约 1.4 GB。

02 · 系统要求

Windows 10 / 11 64 位，或 macOS 11+（Apple Silicon）；建议 16 GB 内存。有 NVIDIA 显卡时推理明显更快，没有也能跑。

03 · 数据位置

对话、资料、配置都在 %LOCALAPPDATA%\Sen（macOS 是 ~/Library/Application Support/Sen），卸载时会询问是否保留。
